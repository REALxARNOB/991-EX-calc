## 2024-05-19 - Keyboard Navigation and Focus Styling
**Learning:** In vanilla HTML/CSS projects, replacing disabled inputs with readonly is essential for keyboard navigation, but requires careful styling (transparent background, inherit properties, custom focus-visible) to visually match the original un-focusable display while supporting screen readers.
**Action:** Always check if 'disabled' form elements containing critical information can be safely converted to 'readonly' with appropriate styling to ensure keyboard and screen reader accessibility.
