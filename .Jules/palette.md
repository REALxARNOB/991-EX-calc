## 2024-04-24 - Calculator Accessibility Pattern Learnings
**Learning:** For calculator displays, using a `disabled` input prevents screen readers from accessing the content and breaks keyboard focus. Using a `readonly` attribute instead, combined with `aria-label="Calculator Result"`, allows focus and text selection without allowing user typing. Styling the readonly input with `background: transparent`, `border: none`, and `outline: none` while adding a subtle focus state (`box-shadow: inset 0 -2px 0 #ff9f0a`) provides a clear visual indicator without breaking the seamless display appearance.
**Action:** When building custom displays using input fields (like calculators or read-only metric displays), always prefer `readonly` over `disabled` for accessibility, and provide distinct `:focus` and `:focus-visible` styles that blend with the custom container.
