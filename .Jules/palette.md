## 2024-05-24 - Accessible Read-Only Result Input and Icon Buttons
**Learning:** Using `disabled` on input fields prevents them from receiving focus, making them inaccessible to keyboard navigation and preventing text selection. For calculator result displays, using `readonly` combined with appropriate `aria-label` allows focus and text selection while preventing manual typing. Additionally, icon-only buttons like Backspace and Clear must have `aria-label`s (e.g., `aria-label="Backspace"`) to be understandable by screen readers. A subtle `:focus-visible` outline using `box-shadow` on the input improves visibility without layout shift.
**Action:** When creating display-only input fields, use `readonly` instead of `disabled` and add `aria-label`s. Ensure all icon-only buttons have descriptive `aria-label`s. Add `:focus-visible` styles to interactive elements for keyboard navigation support.
