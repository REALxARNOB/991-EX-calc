## 2024-10-27 - [Keyboard Support in Calculator]
**Learning:** Adding keyboard support to a calculator app significantly improves usability for desktop users, transforming it from a mouse-only toy to a functional tool. Ensuring native focus behavior (e.g., Enter on a focused button) is preserved while adding global shortcuts is critical for accessibility.
**Action:** Always map physical keyboard keys to virtual buttons in keypad interfaces, but prevent conflicts with native button activation.
