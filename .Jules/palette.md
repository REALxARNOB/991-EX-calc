## 2025-04-12 - Calculator Display Accessibility & Styling
**Learning:** For a more modern and accessible look, using a `readonly` text input with `background: transparent` and `border: none` allows the input to seamlessly blend into its container while still allowing users to select/copy the result text. A subtle `box-shadow` inset can indicate focus without shifting the layout. Additionally, relying on `:focus-visible` with `outline: 2px solid #ff9f0a; outline-offset: 2px;` greatly enhances keyboard navigation for custom buttons without cluttering mouse interactions.
**Action:** Always prefer `readonly` over `disabled` for result display fields to support text selection and accessibility. Apply seamless styling using `inherit` for typography and transparent backgrounds. Consistently apply `:focus-visible` outlines to interactive elements for keyboard support.
