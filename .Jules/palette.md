## 2024-05-24 - [A11y] Screen Reader Support for Calculator Result
**Learning:** For inputs like the calculator's `#result` that should be focusable, selectable for copying, and readable by screen readers, but not directly editable via keyboard typing, the `readonly` attribute must be used instead of `disabled`. The `disabled` attribute removes the element from the document tab order and prevents screen readers from interacting with or reading its contents reliably. Adding `aria-label` provides necessary context.
**Action:** When implementing read-only display fields that hold important interactive values (like calculation results, generated tokens, etc.), prefer `readonly` over `disabled` and ensure appropriate styling (like custom focus rings using `box-shadow`) to blend seamlessly with the UI while remaining accessible.
