## 2024-03-24 - Calculator Keyboard Accessibility & Visual Feedback
**Learning:** For a calculator app, native input elements provide better a11y out of the box when used creatively. Using `readonly` instead of `disabled` on the result display allows the element to be focused and its value read by screen readers, while still preventing manual text entry. Additionally, explicit `:focus-visible` styles with sufficient contrast (like `#ff9f0a` on dark backgrounds) are crucial for keyboard users to track their position on custom button grids.
**Action:** When building custom interfaces (like calculator keypads or virtual keyboards), ensure display fields remain focusable (`readonly`) and interactive elements have clear, branded `:focus-visible` states that don't shift the layout (using `box-shadow: inset` or `outline` with `outline-offset`).
